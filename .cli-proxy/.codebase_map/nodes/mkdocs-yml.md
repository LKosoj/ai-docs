# Node: mkdocs.yml

## Purpose
MkDocs static site configuration — defines navigation structure, plugins (search, mermaid2), and markdown extensions for generated documentation site.

## Scope
- **File**: `mkdocs.yml` (generated artifact)
- **Generator**: `ai_docs/mkdocs.py:build_mkdocs_yaml()` (dynamically builds config)
- **Output**: `ai_docs_site/` (HTML site via `mkdocs build`)
- **Language**: Russian (nav labels, section titles)

## Instructions for agent
- **Do not edit manually**: This file is regenerated by `ai-docs --mkdocs` on each run.
- **Modify generator**: Changes to navigation/plugins require editing `ai_docs/mkdocs.py:build_mkdocs_yaml()`.
- **Validate**: After regeneration, run `mkdocs build -f mkdocs.yml` to verify no errors.
- **Key functions**: `_build_tree_nav()` (module/config paths), `_tree_to_nav()` (nested structure).
- **Mermaid**: Configured via `pymdownx.superfences` + `mermaid2` plugin (asset: `ai_docs/assets/mermaid.min.js`).

## Source of truth
- **Config file**: `mkdocs.yml` (root directory)
- **Generator**: `ai_docs/mkdocs.py` (build_mkdocs_yaml, _build_tree_nav, _insert_nav_node)
- **Entry point**: `ai_docs/generator_output.py:build_mkdocs()` (calls mkdocs build)
- **Sections**: `ai_docs/generator_shared.py:SECTION_TITLES` (architecture, runtime, testing, etc.)
- **Domains**: `ai_docs/generator_shared.py:DOMAIN_TITLES` (kubernetes, helm, terraform, etc.)

## When to update
- **Auto-regenerate**: Any change to `.ai-docs/*.md`, modules, or configs triggers rebuild.
- **Generator changes**: Modify `ai_docs/mkdocs.py` to add/remove sections, plugins, or nav structure.
- **Plugin updates**: Adding MkDocs plugins requires `pyproject.toml` dependency + `build_mkdocs_yaml()` update.
- **Navigation changes**: New sections via `SECTION_TITLES` in `generator_shared.py`.
- **Manual override**: Safe to delete; regenerated on next `--mkdocs` run.

## Related nodes
- `ai-docs.md` — generator package (creates mkdocs.yml)
- `ai-docs-site.md` — generated HTML output
- `pyproject-toml.md` — MkDocs dependencies (mkdocs, mkdocs-mermaid2-plugin, pymdown-extensions)
