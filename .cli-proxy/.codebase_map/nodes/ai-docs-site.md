# Node: ai_docs_site

## Purpose
Generated static documentation site (HTML/CSS/JS) produced by MkDocs from `.ai-docs/` markdown sources.

## Scope
- **Source glob**: `ai_docs_site/**`
- **Generated by**: `ai_docs/generator_output.py:build_mkdocs()` → `mkdocs build`
- **Post-process**: `_postprocess_mermaid_html()` fixes `&gt;` in Mermaid diagrams
- **Estimated files**: ~20 HTML + assets (CSS, JS, webfonts)

## Instructions for agent
- **Read-only**: This is a generated artifact; never edit manually.
- **Regenerate**: Run `ai-docs --source . --mkdocs` to rebuild.
- **Validate**: Check `ai_docs_site/index.html` renders correctly after regeneration.
- **Cleanup**: Safe to delete; will be regenerated on next `--mkdocs` run.

## Source of truth
- **Primary**: `.ai-docs/*.md` (markdown sources)
- **Config**: `mkdocs.yml` (navigation, plugins, theme)
- **Generator**: `ai_docs/generator_output.py` (build_mkdocs, _postprocess_mermaid_html)
- **Assets**: `ai_docs/assets/mermaid.min.js` (bundled for MkDocs)

## When to update
- **Trigger**: `--mkdocs` flag passed to `ai-docs` CLI.
- **Auto-update**: Any change to `.ai-docs/*.md`, `mkdocs.yml`, or module/config summaries.
- **Manual regeneration**: `rm -rf ai_docs_site && ai-docs --source . --mkdocs --regen all`.
- **Do not update**: Direct edits to `ai_docs_site/*.html` (will be overwritten).
