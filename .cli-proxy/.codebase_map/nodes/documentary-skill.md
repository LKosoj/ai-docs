# Node: documentary-skill

## Purpose
Claude Code skill package that enables agents to navigate and refactor code using `.ai-docs/` documentation as the primary source of truth.

## Scope
- **File**: `documentary.skill` (ZIP archive, 3.8KB)
- **Internal**: `documentary/SKILL.md` (skill definition)
- **Usage**: Activated when user requests code changes, refactoring, or project understanding

## Instructions for agent
- **Activate**: Use when user asks to "доработай код", "сделай рефакторинг", "сделай детальное описание проекта".
- **Workflow**:
  1. Check `.ai-docs/` exists — if not, tell user to run `ai-docs` first.
  2. Read `.ai-docs/_index.json` for navigation (uses `rules.priority`, `rules.ranking`).
  3. Load key sections: `index.md`, `architecture.md`, `conventions.md`, `dependencies.md`.
  4. Navigate to specific modules via `modules/index.md` + `modules/**/*.md`.
  5. Reference `.ai-docs` files in responses before touching source code.
- **Language**: Respond in the same language as user's question (Russian/English).
- **Do not**: Suggest regenerating documentation.

## Source of truth
- **Skill archive**: `documentary.skill` (ZIP format)
- **Skill definition**: `documentary/SKILL.md` (inside archive)
- **Documentation source**: `.ai-docs/` directory (generated by `ai_docs/generator.py`)
- **Navigation index**: `.ai-docs/_index.json` (priority rules, ranking)

## When to update
- **Skill changes**: Modify `documentary/SKILL.md` and repackage `documentary.skill` when workflow changes.
- **Documentation changes**: Any update to `.ai-docs/` structure (new sections, modules) requires skill review.
- **Generator changes**: Changes to `ai_docs/generator.py` or `ai_docs/generator_output.py` that affect `_index.json` schema.
- **Version bump**: Update skill when `ai-docs-gen` package version changes (`pyproject.toml`).

## Related nodes
- `ai-docs.md` — documentation generator that creates `.ai-docs/`
- `ai-docs-site.md` — generated output (HTML site)
- `ai-docs-cache.md` — incremental generation cache
